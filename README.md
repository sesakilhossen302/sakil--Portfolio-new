# S.E. Sakil Hossen — Portfolio

> Creative Flutter Mobile Application Developer & Software Engineer with 7+ years of experience building high-performance, visually engaging digital experiences.

## 🚀 Features

- **Dynamic Interactive Hero**: Smooth micro-interactions, responsive status badges, animated stats, and glowing halo effects.
- **7-Year Career Journey**: Interactive milestone timeline showcasing key career achievements with custom photography.
- **3D Horizontal Project Showcase**: Smooth horizontal magnetic project track featuring 12 production Flutter applications.
- **Dedicated Project Detail Pages**: Complete project architecture, tech stack breakdowns, key features, and source previews.
- **Client Testimonials & Reviews**: Founder and executive reviews with high-fidelity avatars.
- **Interactive FAQ Accordion**: Smooth collapsible FAQ component for prospective clients.
- **Giant SAKIL Footer Logo & Image Trail**: Custom SVG vector logo banner with real-time interactive mouse hover image trail featuring aesthetic flowers and developer photography.
- **Mobile-First Responsiveness**: Handcrafted responsive suite with high-contrast typography, native snap carousel, and zero overlapping bugs.

---

## 🛠️ Technology Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+), Modern CSS3
- **Animations & Interaction**: GSAP (GreenSock Animation Platform), ScrollTrigger, SplitType, Lenis Smooth Scroll, Swiper.js
- **Frameworks & Mobile**: Flutter & Dart architecture showcase
- **Server**: Lightweight Node.js local development server

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/sesakilhossen302/sakil--Portfolio-new.git

# Navigate into the project folder
cd sakil--Portfolio-new

# Start the local development server
npm start
# or run with node:
node server.js
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
